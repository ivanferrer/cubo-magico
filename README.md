# 🧩 Cubo Mágico 4×4 (Web)

Este é um pequeno jogo de **Cubo Mágico 4×4** que roda diretamente no navegador, desenvolvido com **HTML, CSS e JavaScript**, utilizando **Three.js** para renderização 3D.

O objetivo é simples: **girar as faces do cubo até completar todas as cores corretamente**.

---

## 🎮 Como jogar

- **Arraste uma face do cubo** até selecionar **3 quadradinhos** para girar aquela face.
- **Arraste o fundo** da tela para orbitar a câmera ao redor do cubo.

### Controles

- **Embaralhar** — mistura o cubo automaticamente.
- **Desfazer** — desfaz o último movimento realizado.
- **Resetar** — retorna o cubo ao estado inicial.

---

## 🏆 Vitória

Quando o cubo é resolvido, uma tela de parabéns é exibida, indicando que o desafio foi concluído com sucesso.

---

## 💡 Observações

- Projeto totalmente **client-side**.
- Não requer instalação ou build.
- Compatível com **desktop e dispositivos móveis**.
- Foco em interação intuitiva e visual limpo.

---

## 🚀 Como executar

Basta abrir o arquivo `index.html` em qualquer navegador moderno.
